## 编写检查更新功能

- 右上角设置按钮从原本的弹窗显示改为独立 TAB 页显示
- 重新绘制设置页样式与布局，将原有设置项进行分组，补充设置说明、未保存状态和页面内保存反馈
- 启动后静默检查一次更新，发现新版时在右上角设置按钮和“检查更新”菜单显示新版小红点
- 检查更新页面支持配置代理、检查更新、查看新版本说明、下载安装、跳过更新等功能，目前仅支持 Github 更新源
- 网络代理设置，支持 HTTP / HTTPS 代理及用户名、密码认证，用于检查和下载更新
- 安装更新前确认退出，并沿用会话关闭保护，检查未保存文件和未完成传输
- 尚未包含软件更新功能的旧版本，需要先手动安装本版本；之后可通过“设置 → 检查更新”获取后续版本
