# 远程监控

## 职责与入口

- `ssh/monitor.rs` 的 `collect` 通过现有 SSH 会话执行一次性远端命令并返回监控数据。
- `stores/monitor.ts` 按会话持续采集和缓存，`MonitorPanel.vue` 负责侧栏摘要、网卡选择及系统信息与进程列表入口。
- `ssh/process.rs` 独立查询完整进程列表、单进程详情并执行受限的进程终止操作，进程列表工作区负责按当前会话展示与刷新。
- 采集周期由 `stores/settings.ts` 的应用设置控制。

## 数据与限制

- 数据来自 Linux 的 `/proc`、`/sys`、`/etc/os-release`、`df`、`ps` 和 `uname`；包括系统与 CPU 硬件信息、CPU 分项占用、内存、完整文件系统、进程及网卡累计量和速率。
- 侧栏进程摘要随常规监控采样返回有限条目；完整进程页仅在激活时独立查询全部进程，选中条目的工作目录与环境变量按需读取。
- 系统信息视图打开时固定基本信息、CPU 型号、缓存和文件系统快照；CPU 占用、频率、内存、交换区与网络接口继续使用当前会话的最新采样。
- 系统信息与进程列表分别按连接配置复用工作区选项卡；同一连接切换来源会话或关闭当前来源会话时，视图迁移到该连接的可用会话，最后一个会话关闭时移除。
- 连接工具选项卡激活时隐藏底部文件与传输工作区，切回会话选项卡后恢复原状态。
- 侧栏只展示实际磁盘并自动避开回环接口，系统信息视图保留虚拟文件系统与回环接口以呈现完整信息。
- 监控随会话建立启动、随会话关闭停止，与当前激活的选项卡无关。
- 终止进程使用普通权限发送终止信号，并校验列表读取时的进程身份；目标退出、PID 被复用或权限不足时必须拒绝操作并提示刷新或检查权限。
- ⚠️ 陷阱：监控脚本依赖 Linux 数据源和常用命令；扩展到其他远端系统前，必须新增对应采集实现与解析逻辑。
