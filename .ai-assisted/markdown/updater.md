# 软件更新

## 职责与入口

- `SettingsWorkspace.vue` 是不依附 SSH 会话的单例工具页，包含常规设置和检查更新导航。
- `GeneralSettings.vue` 负责设置草稿、校验和缩放预览；离开常规设置时恢复已保存的缩放。
- `UpdateSettings.vue` 展示更新状态与网络配置；`stores/updates.ts` 持有检查、下载和安装状态，不依赖页面是否打开。
- `src-tauri/src/updater.rs` 封装官方更新插件，管理固定来源、代理、已验证的安装包与安装操作。
- `App.vue` 负责启动检查和安装前退出保护；发布契约见 [发布](release.md)。

## 稳定约束

- 自动检查默认开启，启动完成偏好加载后静默检查一次；关闭后由用户手动检查，不自动下载或安装。
- 标题栏与检查更新菜单使用同一提醒状态；查看页面不会消除提醒，跳过版本持久化后才撤去该版本提醒。
- 检查和下载使用同一代理配置；关闭代理时显式直连，代理地址不接受内嵌凭据。
- 更新代理支持独立用户名和密码；密码保存在系统凭据库，偏好只保存凭据引用，认证由原生层注入代理客户端。
- 保存网络设置不会触发检查；配置变化后必须重新检查成功，才能通过新配置下载更新。
- 客户端只持有公钥，安装包必须通过官方插件签名校验后才能进入待安装状态。
- 安装必须先经过应用退出保护；Windows 交给官方安装器退出重启，其他平台安装后重启应用。
- 更新命令仅允许主窗口调用；开发构建可以检查更新，但禁止下载和安装。
- 新增更新源须同步前端选项、发布页面地址（如有）、跨端类型、原生来源注册和对应的签名发布清单。
